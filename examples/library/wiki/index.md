# Maplewood Public Library — Knowledge Wiki

This is the **narrative** half of the knowledge base: source-cited guidance the
assistant reads for *how* and *why* questions. The **facts** half — exact dates,
dollar amounts, hours, and phone numbers — never lives here. It lives in the
database and is reached through tools (`get_event`, `get_fee`, `get_hours`,
`get_contact`, `get_program`). If you ever see a date or a price written into a
page below, that is a bug, and `./gt check` will fail the build.
