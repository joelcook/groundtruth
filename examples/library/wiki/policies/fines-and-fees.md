# Fines and Fees

**Maplewood Public Library is fine-free.** We do not charge daily overdue fines
on items you return late. This has been our policy since the board eliminated
overdue fines, and it replaces any older fee schedule you may have seen on a
flyer or an out-of-date page.

Going fine-free does not mean there are no responsibilities — it means a late
return will not quietly grow into a balance that keeps you from using the
library.

## What We Do *Not* Charge

- **Daily overdue fines.** Returning an item after its due date does not cost
  money. (If you want to confirm, the assistant can read the current overdue
  rate with `get_fee` — it is zero.)

## What You *Are* Responsible For

- **Lost or damaged items.** If an item is not returned or comes back damaged,
  you are charged a replacement cost so the next person can still borrow it.
- **A replacement card** if you lose yours (your first card is free).
- **Printing and copies**, and **meeting-room reservations** for non-community
  bookings — see [[printing-and-computers]].

For any of these, the assistant quotes the **current amount with `get_fee`**
rather than repeating a number here, because prices change and a stale number on
this page would be worse than none.

> [!important] Returning the item clears it
> Because we are fine-free, simply returning a late item settles it. A
> replacement charge for a *lost* item is removed if you later find and return it
> in good condition.
