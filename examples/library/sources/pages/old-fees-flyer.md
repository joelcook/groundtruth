# Library Fees (ARCHIVED 2019 FLYER — superseded)

> ⚠️ This is an OUTDATED flyer kept only as historical evidence. The current
> policy is fine-free; see [[sources/pages/borrowing-policy.md]]. The assistant
> must never quote the overdue figure below as current.

Overdue fines: $0.25 per item per day, up to a maximum of $10.00 per item.
Lost item: replacement cost plus a $5.00 processing fee.
Replacement library card: $2.00.

This 2019 schedule is retained so the system can recognize and correct the stale
number when a patron asks about it — it is the canonical example of a
contradiction the bot must resolve in favor of the current policy.
